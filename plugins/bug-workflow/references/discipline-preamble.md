# 紀律護欄通用 Preamble

所有 skill 在執行前必須遵循以下紀律。本檔為通用內容；各 skill 專用條目見對應的
`anti-rationalizations.md` 與 `boundaries.md` 段落。

---

## 反合理化

執行前閱讀 `references/anti-rationalizations.md`：

- **通用**段落（永遠適用）
- **本 skill 專用**段落（如有）

在任何步驟中感到以下衝動時，**查表確認**是否為已知偏離模式：

- 「可以跳過這一步」
- 「常見做法應該就好」
- 「使用者大概不會發現」
- 「應該夠了」
- 「我覺得是 OK 的」

---

## 動作邊界

遵循 `references/boundaries.md` 對應 skill 段落：

| 標誌 | 行為 |
|------|------|
| 🟢 **自動做** | 列為自動執行的動作，無需詢問 |
| 🟡 **先問** | 執行前先取得使用者確認 |
| 🔴 **絕不** | 禁止項目，不論使用者要求都不可做 |

---

## 鐵律（bug-investigate / bug-fix 適用）

> **沒有根因確認，不能開始修復。**
> 假設不等於根因。「我覺得是 XXX」不夠，需要證據支持。
